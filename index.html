Arsitektur Pemerintahan Berbasis Elektronik Bappeda Provinsi Lampung TA 2026 yang mengintegrasikan 6 Domain Arsitektur SPBE: Layanan G2E, Proses Bisnis IDP, Satu Data Indonesia (SDI), REST API Berbagi Pakai, Kriptografi TTE BSrE BSSN, dan Penyelarasan IKU Renstra Organisasi.

Enam (6) Domain Arsitektur SPBE Bappeda Lampung (PermenPAN-RB No. 59/2020)

Domain 1 Level 4

Proses Bisnis Terintegrasi

Alur 4 tahap IDP (Perencanaan, Verifikasi, Realisasi 20 JP, Evaluasi Kirkpatrick L1-L4) baku & auditabel.

Domain 2 Level 4

Layanan SPBE G2E & G2G

Portal mandiri bagi 126 ASN Bappeda, dasbor eksekutif pimpinan, dan rekapitulasi data bagi BKD Provinsi.

Domain 3 Level 5

Data & Satu Data Indonesia

Standar metadata SDI, kode referensi NIP BKN, format interoperabilitas JSON Schema baku nasional.

Domain 4 Level 4

Aplikasi SPBE Berbagi Pakai

Aplikasi web progresif (PWA), modul mobile React Native, dan API Gateway multi-transport real-time.

Domain 5 Level 4

Keamanan & TTE BSrE BSSN

Integritas hash SHA-256, sertifikat digital X.509, Timestamp Authority (TSA), dan jejak log audit ISO 27001.

Domain 6 Level 4

Infrastruktur Cloud SPBE

Cloud terdistribusi berdaya tahan tinggi (High Availability), Service Worker PWA, dan sinkronisasi offline-first.
